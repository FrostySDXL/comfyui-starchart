# Examples: Workflows

**Status:** Mixed surface
**Primary Sources:** https://github.com/comfyanonymous/ComfyUI_examples, https://raw.githubusercontent.com/Comfy-Org/docs/main/public/workflow.json

## What Belongs Here

This directory is for real workflow artifacts, curated pointers to official
workflow examples, and narrowly scoped repo-authored workflow fixtures when a
docs or example surface needs a small local pattern.

## Included Examples

- `custom-node-image-selector-workflow.json` - official workflow JSON linked from
  the custom-node walkthrough in the Comfy docs repo
- `api-execution-tracking-workflow.json` - repo-authored starter workflow for
  prompt-submission and execution-tracking examples in this repository

## Recommended Upstream Sources

- `comfyanonymous/ComfyUI_examples` for broader workflow families
- official docs tutorial pages when they provide downloadable workflow JSON

## Evidence Level

- official docs example: walkthrough-linked workflow JSON
- official example repository: `ComfyUI_examples`
- repo-authored workflow pattern: local starter fixture for bounded docs/example
  use
- community workflow repositories: supplementary only and should stay labeled as
  community pattern examples
