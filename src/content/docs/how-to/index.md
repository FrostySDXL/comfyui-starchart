# How-To Section Guide

**Evidence:** Operational guidance
**Last Updated:** 2026-05-13

## Scope

This hub routes readers to focused operational recipes. Use how-to pages when
you already know the outcome you want.

## Choose by outcome

| If you want to... | Start here |
|------|------|
| Install a custom node with the safest supported path for your setup | [Install Custom Nodes Safely](install-custom-nodes-safely.md) |

## Keep these scopes separate

- **Install custom nodes safely** explains end-user installation paths and post-install checks.
- **Enable and use Manager** explains how to make Manager available when it is not already enabled.
- **Integrate with Manager** explains author-facing distribution boundaries and registry-backed expectations.
- **Update ComfyUI** explains install-mode-aware update steps and version-line choices.
- **Troubleshoot custom node breakage** explains how to isolate and confirm failures after installation or updates.
