## Scope

This section routes readers through recurring confusion points already reflected
in the repo's current docs. It is not a general support manual or a full FAQ.

## Quick Answers

- **Is this the official ComfyUI documentation?** No. Use
  [docs.comfy.org](https://docs.comfy.org/) for the official human reference.
- **Can I fork or self-host this repo?** Yes. The repository is MIT-licensed and
  the built site is static.
- **Which JSON artifacts are meant to be stable?** Start with
  [Machine-Readable Artifacts](../reference/machine-readable-artifacts.md) for
  the canonical published contract.
- **Where should contributors start?** Begin with
  [Start Here: Docs Contributor](../start-here/docs-contributor.md) for
  published-doc changes and switch to `CONTRIBUTING.md` when the change crosses
  into scripts, CI, or published artifacts.
